# Cultivator motion lab

Open `/between/cult/motion-lab.html` through a web server. The page plays the current cultivator rig and robe. Walk is the shipped procedural gait. The review run transfers joint directions from CMU capture; jump and climb are first authored drafts from `motion.js`. The orange skeleton is the source reference: walk and run come from our earlier CMU-based cave player, and jump is CMU subject 16 trial 05. The controls change playback speed, leg reach, arm swing, torso lean, run flight, and jump height; values persist in browser local storage.

Run the repo's local preview with `python3 tools/blender-cloud/tests/motion_lab_server.py`. Drag the image to rotate and scroll to zoom. A review note saves to `review-notes.jsonl` with the action, time, controls, and camera view, so later Codex chats and repo work can use the feedback directly. The endpoint binds only to `127.0.0.1`. The cloud capture verifies the note path in an ephemeral runner; notes entered there are captured in its artifact and are not automatically committed to the branch.

**Rig calibration:** select **Pose run**, scrub to a troublesome frame, and adjust the left and right upper arm and forearm directions separately. The shared clearance control opens both arms away from the torso; the eight pose controls change each segment's outward and forward direction. `RUN_RIG_MAP` in `mocap-reference.js` records the source and target joint pairs and the source frame basis. The elbow readout is lateral distance from the torso center, not a mesh-intersection verdict. Saved notes include all calibration values. This lets a reviewer specify a reproducible correction before changing rig mapping or garment geometry.

The source walk/run asset was copied from `content/ontology-game/cave/player/walker.glb` into `reference-cmu-walk-run.glb` (135 KB). The jump BVH is from [the CMU motion capture database, subject 16 trial 05](https://mocap.cs.cmu.edu/search.php?subjectnumber=16), distributed as [BVH conversion by Bruce Hahn](https://github.com/una-dinosauria/cmu-mocap/blob/master/data/016/16_05.bvh). CMU asks users of the data to acknowledge: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”

This is a comparison tool, not a finished animation system. Walk remains the shipped procedural gait. The review run now transfers CMU joint directions to the cultivator, with the orange skeleton beside it. The jump reference covers a longer action than the authored draft, so its normalized timeline is for broad timing comparison, not frame-perfect correspondence. The climb review has a 0.72 m ledge and root travel so the character's approach and ascent can be seen. Hand and foot contacts are still named intent, not locked to the ledge. Root motion, foot plants, collisions, and the climb's ledge contacts are not solved in gameplay. Before accepting any motion or robe, review in playback, implement contact constraints, and rerun the cloud captures.
