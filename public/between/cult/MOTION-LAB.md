# Cultivator motion lab

Open `/between/cult/motion-lab.html` through a web server. The page plays the current cultivator rig and robe. Walk is the shipped procedural gait. Run, jump, and climb are first authored drafts from `motion.js`. The orange skeleton is a reference, not a retargeted cultivator clip: walk and run come from our earlier CMU-based cave player, and jump is CMU subject 16 trial 05. The controls change playback speed, leg reach, arm swing, torso lean, run flight, and jump height; values persist in browser local storage.

The source walk/run asset was copied from `content/ontology-game/cave/player/walker.glb` into `reference-cmu-walk-run.glb` (135 KB). The jump BVH is from [the CMU motion capture database, subject 16 trial 05](https://mocap.cs.cmu.edu/search.php?subjectnumber=16), distributed as [BVH conversion by Bruce Hahn](https://github.com/una-dinosauria/cmu-mocap/blob/master/data/016/16_05.bvh). CMU asks users of the data to acknowledge: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”

This is a comparison tool, not a finished animation system. The reference skeletons are phase-aligned for viewing but are not retargeted to the cultivator. The jump reference covers a longer action than the authored draft, so its normalized timeline is for broad timing comparison, not frame-perfect correspondence. Root motion, foot plants, collisions, and the climb's ledge contacts are not solved in gameplay. Before accepting any motion or robe, review in playback, implement contact constraints, and rerun the cloud captures.
