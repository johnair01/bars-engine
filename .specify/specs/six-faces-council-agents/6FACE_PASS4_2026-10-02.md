## 🧠 Architect, on structure

**One home and a pull, not copies pushed around.** The home repo is named in `council/source.txt`.
Every other repo pulls the shared files from it when a session opens. Those are the definition file
and the skill. The hook lives in `council/hooks/`, because E4 showed `.claude/hooks/` is not safe in
every repo.

## 🏛 Regent, on what to preserve

**Records stay where the decision was made.** Pass one ruled that. The hook pulls only the shared
files and never touches a ledger, a term registry or a glossary. **Lessons are written at home
only**, because the definition file has one author's history and two writers would fork it.

## ⚔️ Challenger, on what gets wrong

**A sync that fails silently is worse than none.** The hook's first line tells the session which
copy it has. When GitHub is unreachable, the session hears that its copy is local and how old it
is. The tests ran the failure case, not only the happy path.

**The real risk is a write in the wrong place.** A lesson typed into a friendcraft copy would be
overwritten at the next session start. The rule is that a lesson recorded away from home goes under
`lessons_pending`, and `collect_lessons.py` at home finds it.

## 🎭 Diplomat, on what bridges

**A new repo should take one command.** `install.py` does it and registers the repo. The uploaded
skill reaches repos that never ran the installer. It now reads the live home copy where it can
fetch a web address, and the bundled snapshot where it cannot.

## 🌊 Shaman, on felt sense

**The ask underneath is to stop carrying the council by hand.** Today Wendell has relayed every
change between repos through this one session. The sync takes that relay off him. The board stays
the one place he acts, because it was always cross-repo.

## 📖 Sage, panoramic

Each face added one piece. The Architect gave the home and the pull, and the Regent kept records
local and gave lessons a single author. The Challenger made failure audible and caught the
wrong-place write. The Diplomat gave the one-command install. The Shaman named the relay the sync
removes. No face dissented on the mechanism. Two questions remain, and both are Wendell's: where the
home lives, and when the waiting branches merge.
